# 🛒 Zepto Integrated Data & AI Platform

An end-to-end data platform built on Windows integrating data engineering, machine learning analytics, and GenAI semantic retrieval into a single Streamlit dashboard.

## 🌟 Key Features
- **Data Engineering (Module 1):** Web scraper for catalog books, storing structured data in SQLite database with query validation.
- **Machine Learning (Module 2):** Scikit-Learn Random Forest model (~80.90% test accuracy) predicting Titanic survival metrics.
- **GenAI Support Assistant (Module 3):** RAG pipeline using FAISS vector indexing and `all-MiniLM-L6-v2` embeddings for fast FAQ retrieval.
- **Unified UI:** Multi-tab Streamlit web application.
